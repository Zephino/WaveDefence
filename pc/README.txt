Wave Defence — PC (Windows)

Contents after export:
  WaveDefence.exe   ← double-click to play

Send this whole folder (or just the .exe) to play on a Windows PC.

Game code is edited once in the main Wave Defence project.
To refresh this folder after code changes, run from the project root:

  .\export_builds.ps1 -PcOnly
  or
  .\export_builds.ps1
